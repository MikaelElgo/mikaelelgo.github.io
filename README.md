# mikaelelgo.github.io

Source for my personal portfolio: https://mikaelelgo.github.io

A single-page site covering my background in reservoir geophysics and petroleum geomechanics — seismic inversion, well-log analysis, 3D land seismic acquisition QC, and a self-directed 1D Mechanical Earth Model (MEM) project — with a flagship case study on Talang Akar sandstone reservoir characterization and a downloadable CV. ## Featured work

• Sandstone Reservoir Characterization, Talang Akar Formation — 3D pre-stack seismic and log data from six wells, Linear Programming Sparse Spike (LPSS) inversion for Acoustic, Shear, and Extended Elastic Impedance (AI/SI/EEI). Bachelor's thesis, Institut Teknologi Bandung.

• Poseidon — Self-Directed 1D Mechanical Earth Model — independent Python pipeline converting dynamic logs to elastic moduli, building a 1D stress profile, and screening wellbore stability against a Mohr-Coulomb criterion. Explicitly Tier C, uncalibrated, screening-level.

• Blind-Well Lithofacies Prediction, FORCE 2020 — reproducible ML pipeline on public well-log data, using group-based (well-level) train/test splitting to test generalization across unseen wells.

• 3D Land Seismic Acquisition Geometry QC — SPS/RPS/XPS validation and VISTA survey-geometry QC across two large 3D land seismic surveys (LAPI ITB).
